## MÜHLE at a glance

| | |
|---|---|
| Game | Nine men's morris, 24 points, 9 pieces each |
| Rules | Tournament rules of the World Mill Federation (WMD) |
| Modes | Computer Easy, Medium, Hard and Two players on one device |
| Content | Two board styles, glowing mills, trays as supply, hints, undo, stars and statistics per mode |
| Platform | Progressive web app for iPhone and iPad, runs in every modern browser |
| Languages | German and English, chosen by device language |
| Technology | HTML, CSS, JavaScript modules, SVG, Web Audio, Web Worker, no framework, no build step |
| Collection | Part of [MIND PAUSE](../../../README.md), interface from the [shell](../../../shared/README.md), design from [QUEEN](../../../queen/README.md) |
| Address | https://michaeldobner.github.io/mindpause/muehle/ |
| Version | 1.0.0 |
